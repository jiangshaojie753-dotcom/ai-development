# IELTS Tracker · 雅思学习管理系统

个人雅思学习记录、量化评估与阶段管理项目。

## 职责分工

- **ChatGPT**：听力/阅读错题分析、口语互动与纠错、写作批改、生成结构化 JSON 学习报告。
- **IELTS Tracker**：每日计划及打卡、四科训练记录、错误复发追踪、可比训练趋势、阶段管理、报告导入、跨设备数据同步。
- **Codex**：在本仓库维护和开发上述应用。

## V1 计划

1. 响应式简体中文网页（移动端和桌面端）。
2. 首页今日任务：预计时长、实际时长、完成状态。
3. Listening / Reading / Speaking / Writing 四科独立数据记录。
4. ChatGPT JSON 报告导入与格式校验、重复导入防护；JSON/CSV 导出备份。
5. 7/30/90 天学习统计；相同条件的练习才比较准确率。
6. 分科 Stage 1–4，按可核验的多次训练证据升级，升级由用户确认。
7. GitHub Pages 部署；云端同步需独立数据库和安全的用户登录，不要把个人记录提交公开仓库。

请参照 GitHub Issues 中的 **IELTS Tracker V1** 详细开发任务进行实现。

## 隐私与数据完整性

仓库只存应用代码与无敏感内容的测试样例，不存个人学习记录、口语音频、邮箱或密钥。未知成绩/时长记作 `null`，不自动推测。AI 对雅思写作/口语的 Band 判断必须标注为参考性估计。

## 开发约定

使用 feature branch 和 Pull Request；禁止强制推送或覆盖与 IELTS Tracker 无关的文件。README、使用说明与验收步骤以中文呈现。
